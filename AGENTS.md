# AI Agents

tomeshelf is a self-hosted EPUB reader. It renders book content into the main page, with no iframe and no shadow DOM, so browser extensions such as ENX work on it.

## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues for `wiloon/tomeshelf`, via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five default labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one root `GLOSSARY.md` and ADRs in `docs/adr/`. See `docs/agents/domain.md`.
